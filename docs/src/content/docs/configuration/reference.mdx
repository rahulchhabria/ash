## Globals

```toml
workspace = "~/.ash/workspace"
timezone = "America/Los_Angeles"
```

| Key | Type | Default |
|-----|------|---------|
| `workspace` | path | `~/.ash/workspace` |
| `timezone` | string (IANA TZ) | system timezone |

## Models (`[models.<alias>]`)

```toml
[models.default]
provider = "openai-oauth"
model = "gpt-5.2"
temperature = 0.7
max_tokens = 4096
reasoning = "medium"
```

| Key | Type | Notes |
|-----|------|-------|
| `provider` | `anthropic` \| `openai` \| `openai-oauth` \| `pioneer` | Required |
| `model` | string | Required |
| `temperature` | float \| null | Optional |
| `max_tokens` | int | Default `4096` |
| `thinking` | `off|minimal|low|medium|high` \| null | Anthropic-specific |
| `reasoning` | `low|medium|high` \| null | OpenAI-specific |

## Browser (`[browser]`)

```toml
[browser]
enabled = true
provider = "sandbox"
timeout_seconds = 30.0
max_session_minutes = 20
artifacts_retention_days = 7
state_dir = null
default_viewport_width = 1280
default_viewport_height = 720

[browser.sandbox]
headless = true
browser_channel = "chromium"
runtime_required = true

[browser.kernel]
api_key = null
base_url = "https://api.onkernel.com"
project_id = null
```

| Key | Type | Default |
|-----|------|---------|
| `enabled` | bool | `true` |
| `provider` | `sandbox` \| `kernel` | `sandbox` |
| `timeout_seconds` | float | `30.0` |
| `max_session_minutes` | int | `20` |
| `artifacts_retention_days` | int | `7` |
| `state_dir` | path \| null | `null` |
| `default_viewport_width` | int | `1280` |
| `default_viewport_height` | int | `720` |
| `browser.sandbox.headless` | bool | `true` |
| `browser.sandbox.browser_channel` | `chromium` | `chromium` |
| `browser.sandbox.runtime_required` | bool | `true` |
| `browser.kernel.api_key` | secret \| null | `null` |
| `browser.kernel.base_url` | string | `https://api.onkernel.com` |
| `browser.kernel.project_id` | string \| null | `null` |

For `provider = "sandbox"`, browser execution is expected in sandbox/container runtime.
Set `browser.sandbox.runtime_required = false` only for local development/testing.

For Kernel, set `provider = "kernel"` and provide `KERNEL_API_KEY`. Ash creates a
remote browser session, connects over CDP, and deletes the session when it closes.

Install Playwright Chromium:

```bash
uv run playwright install chromium
```

## Vapi (`[vapi]`)

```toml
[vapi]
enabled = false
auth_required = true
assistant_id = null
phone_number_id = null
base_url = "https://api.vapi.ai"
```

Set `VAPI_API_KEY` and `VAPI_WEBHOOK_SECRET` in the service environment. Outbound
calls require an assistant and an outbound-capable phone number. Ash restricts call
creation to Telegram-dispatched Conduit tasks after an explicit checkpoint approval.

## Event Router (`[event_router]`)

```toml
[event_router]
enabled = true
auth_required = true
max_body_chars = 8000
allowed_sources = []
```

Set `ASH_EVENT_ROUTER_TOKEN` in the service environment. When authentication is
required but no token is configured, event intake fails closed.

## Skills

```toml
[skills]
auto_sync = false
update_interval_minutes = 5

[skills.defaults]
allow_chat_ids = ["12345"]  # Optional default chat allowlist for all skills

[[skills.sources]]
repo = "owner/repo"

[skills.research]
enabled = true
model = "mini"
allow_chat_ids = ["12345"]  # Optional per-skill override
PERPLEXITY_API_KEY = "..."

[skills.gog]
enabled = true

[skills.gog.capability_provider]
enabled = true
namespace = "gog"
command = ["gogcli", "bridge"]
timeout_seconds = 30
```

When `skills.gog.enabled = true`, Ash applies default provider wiring for
`capabilities.providers.gog` (namespace `gog`, command `["gogcli", "bridge"]`,
timeout `30`) unless overridden explicitly. Use `skills.gog.capability_provider`
to keep gog package settings under `[skills.gog]`.

## Capabilities (`[capabilities.providers.<name>]`)

```toml
[capabilities.providers.gog]
enabled = true
namespace = "gog"
command = ["gogcli", "bridge"]
timeout_seconds = 30
```

| Key | Type | Default | Notes |
|-----|------|---------|-------|
| `enabled` | bool | `true` | Disable provider without removing config |
| `namespace` | string \| null | `null` | Optional explicit namespace override |
| `command` | list[string] \| string | required | Bridge command launched by host |
| `timeout_seconds` | float | `30.0` | Provider call timeout (1-300) |

Skill metadata should declare required capability IDs only. Bridge command/container wiring lives in host config.
